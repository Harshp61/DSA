# 🧠 NeetCode 150 — DSA

A collection of solutions to the **NeetCode 150** problem set, covering the most important Data Structures and Algorithms patterns commonly encountered in coding interviews and online assessments.

The purpose of this repository is to build a strong understanding of DSA by solving problems, identifying patterns, and maintaining clear, well-explained solutions.

## 📚 Topics Covered

The repository covers the following topics:

* Arrays & Hashing
* Two Pointers
* Sliding Window
* Stack
* Binary Search
* Linked List
* Trees
* Tries
* Heap / Priority Queue
* Backtracking
* Graphs
* Advanced Graphs
* 1-D Dynamic Programming
* 2-D Dynamic Programming
* Greedy
* Intervals
* Math & Geometry
* Bit Manipulation

## 🎯 Approach

For each problem, the focus is on:

* Understanding the problem and constraints
* Identifying the underlying DSA pattern
* Developing an efficient approach
* Writing a clean and readable solution
* Analyzing time and space complexity
* Understanding why the solution works

The goal is to develop **problem-solving intuition and pattern recognition**, rather than simply memorizing solutions.
